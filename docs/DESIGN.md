# Visual identity (Nov 4, 2026)

Subject: a Surrey mortgage broker who used to be an underwriter and teaches in plain English. The site is a set of letters (the guides) and forms (the tools). The look borrows from the paperwork of a mortgage file, not from software.

## Colour
- Paper `#F6F7F3` page. A cool, slightly green white, not cream.
- Ink `#142B26` text and headings. Deep spruce, used instead of black.
- Spruce `#1E5246` buttons, hero photo field, the closing band, footer base.
- Sage `#E3E9E2` quiet panels (summary sheet, notes).
- Marker `#F0D24B` the underwriter's highlighter. Only for state: current nav item, link hover and focus, the key line in a summary sheet. Never for decoration.
- Pen `#A52F1D` the red pen. Warnings and urgent notes only.
- Rule `#C5CEC6` (green grey) for lines. Muted text `#4F5F59`.

## Type
- Newsreader (reading serif, built for screens) for headings and body: the "letter".
- Figtree for navigation, buttons, forms, tables, labels and figures: the "form".
- Sentence case everywhere. No tracked capitals, no monospace, no arrows.
- Scale: body 19px/1.62, h1 clamp 34 to 56px at 600, h2 clamp 28 to 36px, h3 23px, UI 15 to 16px.

## Composition
- Header: wordmark left, plain text nav on one baseline, one filled button. No pills.
- Home hero: the name "Josh Resvick" set large, the photo bleeds off the right edge at full hero height, one primary button, one outline button, one text link. No icon cards.
- Inner hero: the H1 on paper with a thick spruce rule above it; a narrow "next step" column on the right (book, apply, phone). No full-width coloured slab.
- Pages with five or more sections get a left rail on desktop: the "on this page" list (always open) with a quiet contact block. The article column stays at 68 characters.
- Summary sheet (the short answer at the top of each page) is a statement: rows with dotted leaders between label and value, the key line marked in highlighter. The same leader style is used for calculator results.
- Lists replace card grids: the home "what do you need help with" is an index; the three steps are a real sequence with large numerals; reviews are pull quotes; FAQs are ruled rows.
- One closing band on every page joins the booking prompt and the call-back form, with Josh's face beside it.
- Radius is 3px everywhere. No shadows, no gradients, no hover lifts.

## Details only this subject has
- Dotted leaders between labels and figures, as on a mortgage statement.
- Highlighter on hover and focus for links, as an underwriter marks a file.
- Red pen for anything urgent.
- Tabular figures in every table and result.

## Review against the AI defaults
- Cream, serif, terracotta: not used. Paper is cool, the accent is a functional highlighter, there is no terracotta.
- Near-black plus acid accent: not used.
- Broadsheet hairlines and zero radius: rules appear only where content is a list or statement; the page is not ruled into columns.
- Identical rounded cards, shadows, gradients: removed. Components differ because their content differs.
- Template chrome: no tracked caps eyebrows, no middle-dot meta strings, no arrows, no icon chips, no star rows.
- Revision after review: dropped a planned hanging-heading layout (fragile across 169 page modules) in favour of the left rail; replaced the big-number proof strip with a quiet four-column fact line.
